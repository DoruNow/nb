# Numberblocks Math

A private family-use web app for exploring maths with Numberblock characters.

The current MVP is a single addition screen: `input + input = input` with digits 0–9. Type or tap a number, watch the matching Numberblock appear, and see a small jump when the answer is correct.

Numberblock art comes from [`public/assets/Numberblocks Generator.sb3`](public/assets/Numberblocks%20Generator.sb3). See [`docs/numberblocks-sb3-structure.md`](docs/numberblocks-sb3-structure.md) for the Scratch target/costume tree and how integers should map onto it.

```bash
npm install
npm run dev
```
